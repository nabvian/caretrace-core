# Security

CARETRACE deals with data that, in a real deployment, would be sensitive health
information. If you find a security problem, please tell me privately rather than
opening a public issue.

The easiest way is GitHub's private vulnerability reporting — the **Security**
tab on the repository, then **Report a vulnerability**. You can also email me
directly.

It helps if you can include what the problem is and why it matters, how to
reproduce it, the affected commit, and any fix you have in mind.

I'll get back to you as soon as I reasonably can, work through it with you, and
credit you for the report if you'd like that.

One thing to keep in mind: this repository is the core only. The UI, the
integrations, the storage layer and the OCR service are in a separate private
repository and aren't covered here — report anything in those through the private
channel that comes with your access.

And the usual reminder: CARETRACE is an unvalidated prototype and is not for
clinical use (see the [disclaimer](DISCLAIMER.md)). A security fix doesn't change
that.
