# Code of conduct

This is a small project and the expectations are simple.

Treat people with respect. Assume good faith, keep criticism about the work
rather than the person, and help newcomers where you can. Harassment, personal
attacks, and posting someone's private information aren't welcome and won't be
tolerated.

Because of what this project is about: never share real patient information in
any project space — issues, pull requests, discussions, anything.

If someone's behaviour is a problem, or you've been on the receiving end of it,
contact me and I'll deal with it. I'll keep reports private.

This is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org).

— Koushik Das
